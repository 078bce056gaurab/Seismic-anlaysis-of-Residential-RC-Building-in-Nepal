#  Seismic Vulnerability Assessment & Retrofit of Pre-Code RC Buildings — Nepal

This project evaluates the seismic vulnerability of a pre-code residential RC building
in Kathmandu, Nepal, and assesses retrofit interventions for compliance with NBC 105:2020.
Analysis includes nonlinear pushover methods and nonlinear time history analysis.
Retrofit intervention investigated is concrete jacketing.

---

## Overview

| Item | Detail |
|------|--------|
| Building type | Residential RC frame, pre-code era (pre-1994) |
| Location | Kathmandu Valley, Nepal |
| Target standard | NBC 105:2020 |
| Analysis type | Nonlinear static (pushover) & nonlinear time history |
| Retrofit scheme | Concrete jacketing |
